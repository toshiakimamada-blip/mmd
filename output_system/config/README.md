# config

アプリに同梱する設定ファイルの置き場です。コンテナのイメージの `/app/config` に入ります（環境変数 `MMD_CONFIG_DIR` で場所を変えられます）。

| ファイル | 中身 |
|---|---|
| `tuning.toml` | 調整値（発話の区切りの長さの上限、警告を出すしきい値、文章生成モデルへ一度に渡す量、CPU の割り当てなど）。値はすべて仮置きで、利用者の PC で測った結果をもとに見直します |
| `models.toml` | AI モデルの定義（名前・役割・配布元・固定した版・ファイルごとの大きさと SHA-256・ライセンス名）。起動のときに読み込んで検証します |
| `translation_alternatives.md` | 翻訳モデル（FuguMT）を業務で使えないと分かった場合に備えた、代わりの候補（配布元・ライセンス・注意点）。アプリは読みません |

## 調整値の扱い

- `tuning.toml` が既定値の唯一の置き場です。コードの中には既定値を持ちません。
- 環境変数で上書きできます。名前は、項目名を大文字にして `MMD_TUNING_` を付けます（例: `utterance_max_seconds` は `MMD_TUNING_UTTERANCE_MAX_SECONDS`）。
- 起動のときに、すべての項目の型と範囲を検証します。知らない項目、足りない項目、範囲の外の値は、起動を止めます。
- 項目を足すときは、`tuning.toml` と `backend/src/meeting_interpreter/tuning.py` の `Tuning` に同じ名前で足します。過不足は自動テストで検出します。
- 設定を画面から変える機能は設けません。見直しは、このファイルを書き換えたアプリの更新として行います。
- 秘密の情報（パスワード・鍵）は置きません。

動かす場所で変わる値（通す宛先の名前、待ち受けのポート、記録データベースとモデル置き場の場所、ログのレベル）は、このフォルダに置きません。`docker-compose.yml` の環境変数で渡します。

## AI モデルの定義の扱い

- `models.toml` は、アプリが入手するファイルと、確かめる SHA-256 の唯一の置き場です。コードの中には書きません。
- 版（`revision`）は、配布元のリポジトリのコミット（40 桁）で固定します。ブランチ名・タグ・「最新」は読み込みで失敗します。
- 入手先は `<repository_url>/resolve/<revision>/<ファイル名>` です。HTTPS だけで入手します。
- 業務で使えるライセンスの AI モデルだけを書けます。非商用に限るライセンス名（CC BY-NC など）は、読み込みで失敗します。
- 起動のときに、すべての項目を検証します。誤りは見つけたものをすべてまとめて知らせ、起動を止めます。
- 翻訳モデルのライセンスの補足（`license_note`）に、確認中の事項を残します。FuguMT は、作者の「研究用を目的に公開」の記載について、利用者が社内で確認中です。
- 版を上げるときは、配布元の API が返す LFS の sha256 を使います。値を公開していない小さなファイルは、固定した版のファイルを入手して `sha256sum` で求め、出どころを `models.toml` のコメントに残します。
