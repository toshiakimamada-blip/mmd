# 翻訳モデルの代わりの候補

`models.toml` の翻訳モデル（FuguMT 英語から日本語）は、仮置きです。作者の README に「本モデルは研究用を目的に公開しています。」の記載があり、業務で使えるかを、利用者が社内の法務・知財部門に確認中です。

この文書は、FuguMT を業務で使えないと分かった場合に備えた、代わりの候補の一覧です。調べた日は 2026-10-23 です。

## この文書の位置づけ

- 配布元の表示（モデルカードとリポジトリの情報）を転記したものです。ライセンスの法的な判断は、していません。採用する前に、利用者が社内の規程に沿うかを確認してください。
- 訳の質は、この PC で測っていません。採用を決めたら、見本の英語音声で FuguMT と比べます。
- 候補の版（コミット）は、調べた日に最新だったものです。採用するときに、`models.toml` へ固定した版と SHA-256 を書き直します。
- 条件は、非商用に限るライセンスを除くことです（要件「配布形態とライセンス」）。

### 候補ごとの確かめた事実と注意

ElanMT-BT

- 開発元は ELAN MITSUA Project / Abstract Engine。学習に、CC0・CC BY・CC BY-SA など公開ライセンスのコーパスだけを使ったと、モデルカードに書かれています。Web を巡回して集めたデータと、他の翻訳モデルの出力は使っていないと書かれています。
- モデルカードの評価（FLORES+ の devtest、BLEU）では、ElanMT-BT が 29.96、FuguMT が 30.89 です。開発元による評価で、この PC では未確認です。
- ライセンスは FuguMT と同じ CC BY-SA 4.0 です。「研究用を目的に公開」の記載は、モデルカードにありません。一方で、モデルカードの免責事項に「翻訳の正確性が必要なユースケースでの使用には適していません」と書かれています。
- 同じ開発元に、より小さい ElanMT-tiny（15M パラメータ）もあります。FLORES+ の BLEU は 25.93 です。

OPUS-MT en-jap

- 開発元は Helsinki-NLP（OPUS-MT プロジェクト）。モデルカードのライセンス欄は Apache 2.0 です。
- モデルカードの評価は、聖書の対訳（bible-uedin）だけです。会議の発話に近い文での質は、確かめられません。FuguMT より劣る可能性が高く、最後の手段の位置づけです。

M2M100 418M

- 開発元は Meta（Facebook AI）。モデルカードのライセンス欄は MIT です。
- 日本語への翻訳の質は、モデルカードから確かめられません。ファイルが 1.9GB（32 ビット浮動小数点数）あり、入手と変換にかかる時間とメモリが、FuguMT の約 120MB より大きくなります。

## 調べたが候補にしないもの

| モデル | 候補にしない理由 |
|---|---|
| NLLB-200（facebook/nllb-200-distilled-600M など） | ライセンスが CC BY-NC 4.0 で、非商用に限られます（ADR-05 で却下済み） |
| facebook/mbart-large-50-many-to-many-mmt | 配布元のモデルカードにライセンス欄が無く、確かめられません。610M パラメータで、メモリの配分にも収まりにくい |
| google/madlad400-3b-mt | ライセンスは Apache 2.0 ですが、3B パラメータ（ファイル 11.8GB）で、約 8GB のメモリの配分に収まりません |

## 採用するときの手順

1. 利用者が、候補のライセンスを社内の規程に沿って確認します。
2. 候補の版と各ファイルの SHA-256 を、`models.toml` の翻訳モデルに書き替えます（出どころの書き方は `models.toml` の冒頭を参照）。
3. 翻訳モデルの変換の手順（Marian の構造なら現行のまま）を確かめます。
4. 見本の英語音声で、訳の質と字幕の遅れを FuguMT と比べます。
